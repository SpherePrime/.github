### 🟠 About the Organization

**SpherePrime** — команда из двух разработчиков, создающих собственную экосистему: голосовые ассистенты, AI-инфраструктура и developer-инструменты.

Флагманское направление — **PrimeRouter**: единая точка входа к LLM-провайдерам, голосовым сервисам и плагинам. Уже выпущен плагин для **Astra** (голосовой ассистент) и в активной разработке собственный **CLI**.

> 💡 *Связь с командой: [Telegram @SpherePrime](https://t.me/SpherePrime) | [Discord](https://discord.gg/jAG3PN43Uf)*

### 🟠 Ecosystem

- **Astra** — голосовой ассистент (KNICE TECH / MINICE). SpherePrime — внешняя экосистема: плагины, STT/TT, прокси.
- **PrimeRouter** — центральная маршрутизация LLM-провайдеров для любой кодовой базы.
- **PrimeProxy** — сетевой слой для обхода региональных блокировок.
- **CLI** — единая точка управления инструментами SpherePrime из терминала.
